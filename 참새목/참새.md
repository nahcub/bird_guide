# 참새 (Eurasian Tree Sparrow)

## 기본 정보

| 항목 | 내용 |
|------|------|
| 학명 | *Passer montanus* (Linnaeus, 1758) |
| 분류 | 참새목 > 참새과 > 참새속 |
| 영어 이름 | Eurasian tree sparrow, Tree sparrow |
| 몸길이 | 약 12.5~14cm |
| 날개 편 길이 | 약 21cm |
| 몸무게 | 약 24g |
| 분포 | 유라시아 온대 지역과 동남아시아 |

## 개요

참새는 유라시아에 널리 사는 작은 새예요. 머리 꼭대기와 뒷목은 밤색이고, 새하얀 뺨마다 검은 반점이 하나씩 있어서 알아보기 쉽습니다. 주로 씨앗을 먹고, 사람이 사는 곳 가까이에서 흔히 볼 수 있어요. 개체 수가 많아 전 세계적으로는 멸종 걱정이 크지 않지만, 서유럽에서는 수가 많이 줄었습니다.

## 분류와 이름

1758년 린네가 『자연의 체계』에서 처음 기록했고, 처음 붙인 학명은 *Fringilla montana*였어요. 처음에는 되새류가 속한 되새과로 분류했지만, 얼마 지나지 않아 1760년 프랑스의 동물학자 브리송이 만든 참새속(*Passer*)으로 옮겨졌습니다.

학명의 *Passer*는 라틴어로 '참새', *montanus*는 '산의'라는 뜻이에요. 하지만 참새는 산새가 아니라서 이름이 서식지와 잘 맞지 않습니다. 오히려 '들참새'에 해당하는 독일어 이름(Feldsperling)이나 헝가리어 이름이 서식지를 더 잘 나타내요. 영어 이름 *tree sparrow*는 나무 구멍에 둥지를 틀기 좋아해서 붙었습니다.

미국에서는 토종인 '아메리칸 트리 스패로우(American tree sparrow)'와 구별하려고 *Eurasian tree sparrow*, 또는 독일에서 들여왔다고 해서 '독일 참새'라고 불러요. 두 새는 이름만 비슷할 뿐 서로 다른 과에 속하며 가까운 친척이 아닙니다.

## 생김새

어른 새는 머리 꼭대기와 뒷목이 진한 밤색이에요. 하얀 뺨에는 콩팥 모양의 검은 반점이 있고, 턱과 목구멍도 검습니다. 등은 연한 갈색에 검은 줄무늬가 있고, 갈색 날개에는 가느다란 흰 줄이 두 개 나 있어요. 다리는 옅은 갈색이며, 부리는 여름에 납빛이 도는 푸른색이다가 겨울에는 거의 검은색으로 바뀝니다.

참새속에서는 드물게 암수의 깃털 색이 같아서 겉모습만으로는 구별하기 어려워요. 어린 새도 어른과 닮았지만 색이 조금 더 흐립니다. 집참새보다 약 10% 작고, 머리가 회색이 아니라 밤색이라는 점으로 구별할 수 있어요.

가을에는 깃털이 천천히 모두 새로 갈이 됩니다.

## 분포와 서식지

자연 번식지는 북위 약 68도 남쪽의 유럽과 아시아 온대 지역에서 동남아시아의 자바와 발리까지 이어져요. 대부분 지역에서는 한곳에 머무는 텃새이지만, 가장 북쪽에서 번식하는 무리는 겨울에 남쪽으로 이동합니다.

유럽에서는 나무가 드문드문 있는 한적한 시골 들판에 주로 살고, 도시에는 집참새가 삽니다. 반대로 동아시아에서는 참새가 도시와 마을에서 흔히 보이는 새예요. 학명과 달리 산에 사는 새는 아니어서, 스위스에서는 해발 700m 정도까지만 보이지만 네팔에서는 4,270m에서 번식한 기록이 있습니다.

원래 분포하지 않던 곳에도 사람이 들여왔어요. 1870년 4월 말 독일에서 데려온 20마리(12쌍이라는 기록도 있음)를 미국 세인트루이스에서 풀어놓았고, 지금은 그 후손 약 1만 5천 마리가 세인트루이스 주변과 일리노이주, 아이오와주 남동부에 퍼져 있습니다. 호주에서는 멜버른과 빅토리아주 일부 도시에 살아요. 반면 뉴질랜드와 버뮤다에서는 자리를 잡지 못했습니다.
