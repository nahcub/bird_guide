# 케이프앵무 (Poicephalus robustus)

![케이프앵무](https://commons.wikimedia.org/wiki/Special:FilePath/Poicephalus_robustus_-South_Africa-6a.jpg?width=600)

*남아프리카공화국 콰줄루나탈 카르클루프에서 촬영한 케이프앵무. 출처: Wikimedia Commons*
## 개요

케이프앵무는 남아프리카공화국에만 사는 큰 앵무새예요. 온대 지역의 산지 숲에서 살며, 영어로는 Levaillant's parrot이라고도 부릅니다. 예전에는 갈색목앵무의 아종으로 여겨졌지만, 지금은 별개의 종으로 구분해요. 개체 수가 적고 서식지가 점점 줄고 있어서 보호가 필요한 새로 꼽힙니다.
## 기본 정보

| 항목 | 내용 |
|------|------|
| 학명 | *Poicephalus robustus* |
| 분류 | 앵무목 > 앵무과 (Psittacidae) > 긴날개앵무속 (Poicephalus) |
| 몸길이 | 약 25~34cm |
| 분포 | 남아프리카공화국 동부와 북동부의 산지 숲 |
| 주요 먹이 | 옐로우우드 나무의 열매 속 씨앗, 견과류 |
| 보전 상태 | 위협받는 종 (자료에 따라 취약 등급으로 표기) |
