## 기본 정보

| 항목 | 내용 |
|------|------|
| 학명 | *Meleagris gallopavo* |
| 분류 | 닭목 > 꿩과 > 칠면조속 |
| 몸길이 | 약 90~125cm |
| 분포 | 북아메리카의 미국, 멕시코, 캐나다 일부 지역. 다른 지역에는 도입된 개체군이 존재함 |
| 국내 관찰 시기 | 야생 자생종이 아니며, 사육 개체는 연중 관찰 가능 |
| IUCN 등급 | 관심대상종(LC, Least Concern) |

## 개요

칠면조는 꿩과 칠면조속에 속하는 대형 조류로, 북아메리카가 원산지이다. 몸집이 크고 목이 길며, 넓은 부채 모양의 꼬리를 가진 것이 특징이다. 주로 땅 위에서 생활하지만 위험을 피하거나 잠자리를 찾을 때 나무 위로 날아오르기도 한다.

야생 칠면조는 숲과 초지, 관목 지대 및 농경지 주변에서 생활한다. 식물의 씨앗과 열매, 견과류, 곤충 등 다양한 먹이를 섭취하는 잡식성 조류이다.

칠면조는 오래전부터 인간에게 식용으로 이용되어 왔으며, 현재는 고기 생산을 목적으로 세계 여러 지역에서 사육된다. 특히 북아메리카에서는 추수감사절과 같은 명절 음식으로 잘 알려져 있다.
